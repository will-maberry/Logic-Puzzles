# Constraint-Satisfaction Puzzles (CSPs)

- **Queens:** Place one queen in each row, column, and colored region without any two queens sharing a diagonal.

- **Tents:** Place one tent next to each tree in the grid, matching row and column clues. Tents cannot touch, including diagonally. Easy uses 5×5–7×7 boards, Medium 8×8–10×10, and Hard 12×12–15×15. The minimum tent counts for those sizes are 7, 9, 12; 15, 20, 22; and 31, 36, 42, 48 respectively.
