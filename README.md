# Constraint-Satisfaction Puzzles (CSPs)

- **Queens:** Place one queen in each row, column, and colored region without any two queens sharing a diagonal.

- **Tents:** Place one tent next to each tree in the grid, while adhering to the number of tents in each row and column. Still a Work In Progress (WIP)

Game and homepage symbols use self-hosted Font Awesome Free 6.7.2 SVGs under. The included `LICENSE.txt` in the `static/icons` directory contains their license and attribution.
