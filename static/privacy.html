DATA & PRIVACY

You keep your data.

Only minimally required game data is sent to the API. This website does not support cookies, analytics, or advertising trackers.

IN YOUR BROWSER

Saved games and theme

Games can save one puzzle and its current board configuration in your browser's local storage. A saved game expires after 30 minutes when you load it or when you begin a new puzzle. Your site theme preference is also stored in your browser's local storage.

ON THE SERVER

Puzzle requests

The API receives a board size from the selected difficulty when generating a puzzle. To check a move, it receives the puzzle clues and current queen or tent placements. The API rate limits requests by IP address.
